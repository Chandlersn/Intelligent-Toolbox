收藏箱悬浮球 · 跨页面一键收藏

这是任意一个页面的示例。右下角（或你拖动到的位置）那枚赤陶橙“收”球，就是全局悬浮收藏器——它不属于这个页面，而是常驻在任意页面 / webview 之上。

怎么用

  • 复制一个 GitHub 仓库链接，点一下球 → 自动从剪贴板收藏
  • 把链接文字拖到球上 → 松手即收藏
  • 点一下球（剪贴板里没有链接）→ 弹出输入框手动粘贴
  • 拖动球可移动，松手吸附到屏幕边缘，位置会被记住

嵌入你自己的页面

只需一行脚本，悬浮球即出现在你的任何页面 / 应用 webview 里：

<script src="ball.js"></script>

可选设置收集端点：window.REPO_COLLECTOR = "https://你的域名/collect"（默认同域 /collect）。

下面是一段占位内容，方便你滚动页面、感受“球始终悬浮在上方”的体验。向下滑，球不会消失；切到别的页面（同样引入 ball.js 的），球也在原位。这就是“随时、跨平台、一键拖入”的收集层。

占位文字：开源仓库的发现场景已从网页搜索转向短视频与社区推荐。当仓库链接出现在视频简介、评论或聊天里，用户需要的不是“再开一个工具”，而是一个随手可触的入口。悬浮球正是这个入口——它把收藏动作压缩成一次点按或一次拖拽，其余的交给后台分析与图谱。
