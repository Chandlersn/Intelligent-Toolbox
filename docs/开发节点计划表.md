## 执行节奏约定
- 每个节点独立可验证，先跑通再叠加。
- M0–M2 构成"收藏→卡片→图谱"最小闭环，是产品价值成立的硬证据，优先做完。
- 分析层（M1 起）本地启发式先行、LLM 后置，保证零依赖可跑、可平滑升级。
- 所有 UI 严格复用主题变量（暖纸白 + 暖陶土 `--accent` 系），去 emoji、纯文字标签。
- **改动业务前先有测试**：M9 之后任何修 bug 都先写一条会失败的回归，再动手（见 `tests/`）。

## 风险与对策
| 风险 | 对策 |
|------|------|
| 冷启动信号稀疏（前 10 个仓库难说缺角） | 缺角标注 `source=seed`（编者先验）；样本 < 5 时页面明示"先当观察" |
| "缺角"推断荒谬 | 仅用弱协同推断，明确标"可能感兴趣"；真实数据部分另开「领域相邻」板块 |
| 卡片变死档案馆 | M3 起卡片驱动下一步动作（合并/联动/补实战）—— 尚未实现「用过/弃了」反馈 |
| 外网拉元数据受限 | 启发式分析不依赖外网；meta 缺失时降级 `pending_meta` 仍可出基础卡片 |
| 卡片与轴表分叉 | 契约：card 是真源、轴表是派生物；`regenerate`/`worker` 共用落点；`/api/doctor` 自检 + 回归测试 |
| 任意网页可偷删收藏 | 删除/重算/重建要求同源；对外暴露时设 `REPO_TOKEN` |
| GitHub 改版导致抓取失效 | trending 抓取失败降级为空列表 + 缓存，不影响主流程 |

## 下一步建议（按收益排序）
1. **接通 M5**（真机分享直达 + 常驻悬浮球）—— 不接通，画像与缺角永远建立在极稀疏样本上，优先级最高。
2. **缺角换成真共现**：样本够了之后用真实领域共现替代 `SEED_GAP_COOCCUR`。
3. **技术栈轴归一化**：合并近义 topic 变体，避免胶囊云被同一项目的 tag 塞满。
4. **卡片加一字反馈**（用过 / 弃了 / 还想用），把收藏从终点变成轨迹。
5. **多维交叉可视化**：图谱现在只投在 domain 一维上。
